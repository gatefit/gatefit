## The problem

Startups and indie shops wire Stripe, see HTTP 200, and still ship a broken access DB. Replayed webhooks, refunds, disputes, past_due, and cancel-at-period-end do not care that Checkout looked fine.

Gatefit is a **CI pack**, not a billing UI. Goldens assert the entitlement row after the ugly transition.
