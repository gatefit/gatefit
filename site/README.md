# Gatefit docs site

Astro + Starlight app for [edipert/gatefit](https://github.com/edipert/gatefit). Not part of the published `gatefit@0.4.0` npm package.

```bash
npm ci
npm run build
```

Deploy: GitHub Pages via `.github/workflows/pages.yml`. Live URL after Pages is enabled: https://edipert.github.io/gatefit/

Polar checkout: `PUBLIC_POLAR_CHECKOUT_URL` (placeholder `https://polar.sh/` until the product exists). See [docs/polar.md](../docs/polar.md).
